# Homework 6: Expression trees

A class hierarchy for arithmetic expressions, including evaluation, symbolic differentiation, numerical integration, and basic simplification.

[All homework](../README.md)

## Build and run

Requires JDK 21 or newer. Run these commands from this directory:

```sh
javac --release 21 -encoding UTF-8 -d out $(find src -name "*.java")
java -ea -cp out prezentacja.Main
```

The demonstration evaluates and differentiates `2x + 3`, approximates its integral, and shows simplification examples.
