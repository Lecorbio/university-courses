# Homework 9: Generic binary search tree

A generic binary search tree with duplicate rejection, demonstrated with integers and comparable time-of-day objects.

[All homework](../README.md)

## Build and run

Requires JDK 21 or newer. Run these commands from this directory:

```sh
javac --release 21 -encoding UTF-8 -d out *.java
java -ea -cp out Main
```

The demonstration prints two trees, their sizes, and the result of duplicate insertions.
