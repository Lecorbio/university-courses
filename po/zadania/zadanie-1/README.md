# Homework 1: Bilbo object model

An object-model diagram for Bilbo, bags, and treasures, stored in the editable Dia format.

[All homework](../README.md)

## Open the diagram

Open [Bilbo.dia](Bilbo.dia) with Dia. This assignment contains a design diagram and has no executable program.

## Task description

Source: [Moodle — Zadanie 1 (Bilbo)](https://moodle.mimuw.edu.pl/mod/assign/view.php?id=171130). The original [Bilbo scenario (PDF)](Bilbo.pdf) provides the background; the homework requirements below narrow the scope to the Dia diagram.

Proszę dokończyć projekt klas do zadania o Bilbie (z zajęć) w programie Dia.

Potrzebne zmiany:

- Dodać klasę `Postać` — nadklasę `Krasnoluda` i `Bilba` — i przesunąć do niej wspólną funkcjonalność obu tych klas (przyjmowanie skarbów na stałe, pokazywanie posiadanych skarbów).

Nie trzeba dodawać krasnoluda liczącego średnią (ale można). Przy czym wciąż chcemy, żeby każdy krasnolud mógł obejrzeć wszystkie skarby znajdujące się w danym momencie w workach.

Rozwiązania wysyłamy w formie pliku `.dia`.

Original scenario source: [Moodle — Treść zadania o Bilbie](https://moodle.mimuw.edu.pl/mod/resource/view.php?id=170677).
