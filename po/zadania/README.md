## Build and run

Use **JDK 21 or newer**. Each assignment is independent: run the commands in its own README from that assignment's directory. Compiling the whole course together would mix unrelated classes with the same names.

Homework 8 additionally uses Maven, and the performance experiment needs a C++17 compiler. The ski-resort projects include their sample input and existing tests; part 2 also includes the course map generator and test libraries.
