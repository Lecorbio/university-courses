# PO — Programowanie obiektowe

Java coursework from **Programowanie obiektowe**, alongside selected solutions to past colloquia. The projects explore object modelling, encapsulation, inheritance, polymorphism, generics, testing, and simulation.

## Collection

| Section | Contents |
| --- | --- |
| [Homework](zadania/) | Nine smaller assignments, a performance experiment, and two ski-resort simulation projects |
| [Colloquium solutions](kolokwia/) | BigOS, school admissions, elections, and flowerbeds (2022–2025) |

Start with the [ski resort simulator](zadania/duze-zadanie-2/) for the largest project, or browse the [homework index](zadania/) for individual topics.

## Build and run

Use **JDK 21 or newer** and follow the README inside each assignment. Homework 8 uses Maven, the performance experiment uses C++17, and the other Java solutions compile directly with `javac`. Homework 1 is an editable Dia diagram.

Each assignment is a separate program. Compile it in its own output directory, since class names such as `Main` are reused across solutions.

## Documentation

Repository introductions and run instructions are in English. Original assignment statements remain in Polish, as Markdown or authored PDF documents. The homework index links to every statement; each retained colloquium also has its original PDF.
