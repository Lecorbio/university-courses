# Colloquium 2025: Flowerbed

A grid simulation of three flower species with distinct watering behavior and a cyclic winter dance.

[All colloquia](../README.md) · [Original task PDF](<kwiatki.pdf>)

## Build and run

Requires JDK 21 or newer. Run from this directory:

```sh
javac --release 21 -encoding UTF-8 -d out *.java
java -ea -cp out Main
```

The included `Main` recreates the statement’s example and prints the flowerbed before watering, after watering, and after the dance.
